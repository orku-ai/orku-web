# orku-web

Landing page for orku: the logo centred on a sand background. Plain HTML with inline CSS, no build step.

## Local preview

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Any static host works: Cloudflare Pages, Netlify, Vercel or GitHub Pages. Point it at the repo root. There's no build command, and the output directory is `/`.
